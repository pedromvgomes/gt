## Highlights

- **The agtk lockfile is gitignored by default.** A repository with an
  `.agentic-toolkit.yaml` gets `/.agentic-toolkit.lock.yaml` in its
  `.gitignore`, so every fresh checkout has no lock and `agtk sync` locks the
  toolkit's sources at their current heads. There is no bump step to
  remember before working in a repository. `gt repo sync` applies the change;
  if the file is tracked, it asks before running `git rm --cached` (the file
  stays on disk), and declining leaves the lockfile alone.
- **`agent_lock: tracked` opts a repository out.** The default is `ignored`
  and is never written to `.gt-repo.yaml`. Set `tracked` to pin the toolkit's
  sources: sync then removes the exact root entry from `.gitignore` and
  leaves the file tracked. The policy is a spec key because a repository that
  tracks its lock on purpose looks identical, on disk, to one that was never
  migrated.
- **`gt repo check` reports a mismatch as drift**, so a repository picks the
  change up on its next sync without anyone remembering to migrate it.
- **Strict base freshness replaces the merge queue.** Every governed
  repository with `pipeline.ci` enabled is held to its base by GitHub's
  "require branches to be up to date before merging". `gt repo settings
  apply` removes a `merge_queue` rule from the ruleset gt owns.
  `base_freshness` and `require_up_to_date` still parse but nothing reads
  them; `gt repo check` reports a manifest carrying either as spec drift and
  `sync` drops them. See [ADR 0002](../adr/0002-always-strict-freshness-instead-of-a-merge-queue.md).
- **`.lydite/exemptions.yml` is rendered** wherever `lydite.enabled` is true,
  so Dependabot dependency bumps no longer wait on `lydite/referral` for a
  human. See [ADR 0003](../adr/0003-lydite-exemptions-are-managed-not-scaffolded.md).

## Upgrading from v2.1.1

```sh
gt update
gt repo fleet sync             # gitignores and untracks the agtk lockfile,
                               # re-renders the orchestrator and exemptions
gt repo settings apply         # turns on strict required checks and drops
                               # any merge_queue rule gt owns
```

A repository that wants its toolkit sources pinned sets `agent_lock: tracked`
in `.gt-repo.yaml` before syncing.

Worktrees that already hold an ignored lockfile keep it: `agtk sync` only
re-locks when the file is missing, so run `agtk lock` there to advance it.
